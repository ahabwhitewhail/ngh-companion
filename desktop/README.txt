NGH Companion для Windows 10/11 / for Windows 10/11

RU
1. Распакуйте папку целиком.
2. Запустите NGH-Companion.exe. Файл resources.neu должен лежать рядом.
3. Если Windows покажет «Система Windows защитила ваш компьютер»: «Подробнее» -> «Выполнить в любом случае».
Данные хранятся на этом компьютере. Интернет не нужен.

EN
1. Unzip the whole folder.
2. Run NGH-Companion.exe. Keep resources.neu next to it.
3. If Windows SmartScreen appears: More info -> Run anyway.
Data stays on this computer. No internet needed.
